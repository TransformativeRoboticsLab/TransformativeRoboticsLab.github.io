How this model works

1. Non-holonomic blade. A jigsaw blade only cuts along its heading, so it moves like a unicycle: ẋ = v cos θ, ẏ = v sin θ, θ̇ = κv with |κ| ≤ 1/rmin. Wherever the contour's curvature exceeds 1/rmin (sharp corners, tight fillets) the blade must stop.

2. Decomposition. Those points split the contour into cuttable sections (abstract: “decomposes input shapes into cuttable sections”).

3. Drill holes as set coverage. Candidate holes sit in the waste just inside each stop point. A section can start from a hole at either end; if its far end has no hole the blade backs out along its own kerf. Holes are chosen to cover every section while minimising (hole cost × holes) + cutting and back-out distance, the trade-off the abstract describes. This page solves it exactly by enumerating hole subsets; the chart shows the best travel distance for each number of holes.

Assumptions of ours: only an interior cut-out is planned (waste inside), the robot's traversal between holes and the drilling step are not costed beyond the hole weight, and rmin is a free parameter rather than the value of the authors' robot.
